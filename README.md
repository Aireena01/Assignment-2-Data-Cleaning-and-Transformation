# 🧹 Data Cleaning and Transformation

This project focuses on essential data preprocessing techniques to ensure dataset accuracy, consistency, and usability. The tasks below outline the steps required to clean and format a dataset effectively.

---

## 1️⃣ Handling Missing Values
- Check for missing values in the **`Price`** column.
- Handle products with missing price information using imputation or removal strategies.
- If categories are missing, propose a method to fill or manage these missing values effectively.

---

## 2️⃣ Correcting Inconsistent Data
- Identify inconsistent text formats in the **`Product Name`** column.
- Detect and fix typos in the **`Category`** column.
- Use **Find and Replace** to standardize text formats and correct misspellings.

---

## 3️⃣ Removing Duplicates
- Identify duplicate rows based on all columns.
- Remove any duplicates to maintain dataset integrity.

---

## 4️⃣ Splitting and Merging Data
- Split the **`Product ID`** column into **`Manufacturing Date`** and **`Country Code`**.
- Remove unnecessary characters during splitting.
- Merge **`Brand Name`** and **`Product Name`** into a single column named **`Product Brand`**.

---

## 5️⃣ Number Formatting
- Format the **`Price`** column to **currency format**.
- Format the **`Manufacturing Date`** column to display dates in **`DD-MM-YYYY`** format.

---

## 6️⃣ Conditional Formatting
- Apply **data bars or color scales** to the **`Price`** column for visual insights.
- Create a custom rule in the **`Category`** column to highlight cells where the category is **"Electronics"**.

---

### 🧠 Objective
To clean, structure, and visually enhance the dataset for improved readability and analysis.

### 🛠️ Tools Used
- Microsoft Excel / Google Sheets
- Data Cleaning Functions (Find & Replace, Conditional Formatting)
- Basic Data Imputation Techniques

---

### 📈 Outcome
A well-formatted, error-free dataset ready for analysis or visualization.

---

> 💡 *Tip:* Always validate your cleaned dataset by checking for consistency, completeness, and correct formatting before analysis.
